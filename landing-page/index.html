MCP built in

Ask your agent for a sequence diagram.checkout flow. Watch it appear.

Scrawl runs an MCP server on your Mac. Point Claude Code, Cursor or VS Code at it, and the board you have open updates live as the agent draws. When it adds something off screen, the view follows.

  1. Open Scrawl

    The drawing server starts with the app and stops when you quit.

  2. Connect your agent once

    claude mcp add --transport http scrawl http://localhost:3779/mcp

    For Cursor or any other client, press ⇧⌘C in Scrawl to copy the server URL.

  3. Ask for a diagram

    Then ask for changes: add a cache, recolour a box, move a service. It edits the same board.

FAQ

Questions

Everything worth knowing before you pay $29. Still deciding? See how Scrawl compares.

Is this a subscription?

No. You pay $29 once, and the license doesn't expire.

Which AI tools can draw on my boards?

Any MCP client on the same Mac or private network, including Claude Code, Cursor and VS Code. Web-based connectors that run in a vendor's cloud can't reach a server on your Mac.

Does it work offline?

Yes. Scrawl and its drawing server run on your Mac, and your boards are files on your disk.

What do I need to run it?

A Mac on macOS 14 Sonoma or later, and Node.js 22 or newer. Scrawl finds Node on its own; you can point it somewhere else in Preferences.

Where are my boards saved?

In ~/Documents/Scrawl. You can pick another folder in Preferences, or press ⇧⌘O to open it in Finder.

Can I open my boards without Scrawl?

Yes. Each board is a standard .excalidraw file, an open format that other whiteboard editors can open. Nothing is locked in.
